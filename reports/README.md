# تقارير تحليل مطارات سوريا — `reports/`

## الملفات الجاهزة للتنزيل

| الملف | الوصف |
|-------|-------|
| `تقرير_مطارات_سوريا_المقارن.docx` | **نسخة Word القابلة للتحرير** — الرسوم العشرون مخططات Word أصلية (وليست صوراً): انقر بزر الفأرة الأيمن ← «تحرير البيانات» لتعديل الأرقام، أو غيّر النوع والألوان من تبويب «تصميم المخطط». النصوص العربية داخل الرسوم يعرضها محرك Word نفسه فتظهر سليمة دائماً |
| `تقرير_مطارات_سوريا_المقارن.html` | نسخة HTML ذاتية الاحتواء (خطوط ورسوم مضمّنة)، تفتح في أي متصفح دون إنترنت، مع زر طباعة/حفظ PDF |
| `تقرير_مطارات_سوريا_المقارن.pdf` | نسخة PDF مطبوعة (14 صفحة) للقراءة والمشاركة |
| `charts/c01–c14*.png` | الرسوم البيانية منفردةً (بدقة 150dpi بخط Noto Sans Arabic) |
| `index.html` | صفحة تمهيد للمعاينة الحية |

## محتويات التقرير

1. ملخص تنفيذي بأبرز النتائج
2. المنهجية وتعريفات المؤشرات وتوثيق جودة البيانات (فجوات التسجيل)
3. لوحة مؤشرات مقارنة (19 مؤشراً × 3 مطارات)
4. الاتجاه الزمني والنمو (مقارنة عادلة للفترات المتماثلة)
5. تركيب الحركة (فئات، داخلي/دولي)
6. سوق شركات التشغيل (حصص، تركّز HHI)
7. الشبكة والوجهات (ممر الخليج)
8. إيقاع التشغيل (ساعات، أيام)
9. الأسطول وبصمة المسافات
10. اللاذقية: الجسر الجوي الروسي
11. الخلاصة والمصادر

## إعادة التوليد

```bash
python3 analysis/analyze_airports.py   # المؤشرات + الرسوم (تحتاج: pandas, matplotlib, arabic-reshaper, python-bidi)
python3 analysis/build_report.py       # نسخة HTML
python3 analysis/build_pdf.py          # نسخة PDF (تحتاج: fpdf2, uharfbuzz, Pillow)
python3 analysis/build_docx.py         # نسخة Word قابلة للتحرير (تحتاج: python-pptx, python-docx)
```

المؤشرات الخام بالكامل في `analysis/results/metrics.json` وجداول CSV بجانبها.
